# 棱镜使用指南

适用版本：0.2.2。安装见 [README](../README.md)，各设置见 [配置参考](配置参考.md)。

## 棱镜如何参与聊天

棱镜读取往来，理解角色当时的感受，更新心情并积累场景。整理经历时，将场景、记忆强度与联想关系保存；接入方需要时，获得当前感受与相关回忆。

棱镜不主动发送角色回复。独立安装时可以记录和查看状态；与光谱一起使用时，这些状态成为光谱组织对话的背景。光谱可以单独运行，停用棱镜也不会移除光谱本身的记忆与共同生活功能。

## 初次配置

在“开始使用”选择模型，先保留默认人格、场景整理数量和淡化周期。明确指定模型有利于区分棱镜的调用与主聊天模型的调用。

人格五项控制理解与情绪倾向：开放性、尽责性、外向性、宜人性、情绪敏感性。它们不是角色人设的替代品，也不是对某个人的好感分数。

“特别在意的事情”是可选的JSON对象。新手保留 `{}` 即可；需要时可填 `{"被忽略": 1.5}`，1表示普通敏感程度，大于1更敏感。不要填自然语言段落。

“生成主观回忆文字”控制额外的文字整理；关闭后仍保存基础场景。“基础记忆淡化周期”决定强度减半的参考时长，重要经历和回想会改变实际速度，不会到点删除整条记录。

## 全部指令

| 指令 | 用途 |
|---|---|
| `/棱镜` | 查看当前心情、场景、记忆与联想图数量 |
| `/棱镜 想` | 查看当前可召回的经历；没有相关经历时可为空 |
| `/棱镜 存` | 手动保存当前场景、记忆痕迹和联想图 |

指令没有重建光谱生活状态的作用，`想` 也不是把全部历史导出。`存` 用于手动落盘，并非开启自动记录的必要步骤。

## 数据面板

在 AstrBot 中打开棱镜的插件页面：

| 区域 | 可做的事 |
|---|---|
| 心情与概览 | 查看当前状态和数量，手动设置心情 |
| 场景 | 查看内容、叙事与相关信息，修改回忆文字或删除场景 |
| 记忆强度 | 查看清晰程度，手动加固一条记忆 |
| 联想图 | 查看节点、连接及邻居关系 |
| 人物 | 查看识别到的人物信息 |

面板调整直接作用于棱镜的数据；不会自动改光谱的承诺、行程或客观现状。纠正客观事件时，请同时查光谱中的来源和共同状态。

## 共享设置

可以分别允许共享当前心情、对当前人物的感受、相关回忆和近期联系人身份。关闭共享只停止对外提供该项，不删除已存经历。近期联系人身份有助于区分谁曾经联系过角色。

## 常见问题

**为什么没看到回忆文字？** 先确认开启文字生成、模型可用，并达到场景整理数量或安静整理条件；基础记录和文字整理不是同一时刻完成。

**为什么某段经历淡了？** 强度随时间变化，回想会加固；可在面板查强度和场景。淡化是召回机制的一部分。

**为什么普通问候没有明显情绪变化？** 轻微或中性的互动可以保持原有心情，不要求每句话都有强烈反应。

**光谱没有使用棱镜？** 检查棱镜启用、模型可用、对应共享开关，以及光谱的接入开关。查看加载和调用日志。

**回忆与事实不一致？** 棱镜保存主观体验。先核对源对话；共同现实和约定以光谱相应记录为准，再决定是否修正场景叙事。
