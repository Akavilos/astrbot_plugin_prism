# 棱镜状态模型说明

适用版本：0.2.2。本文解释页面中的状态含义，便于调整配置和理解回忆变化。

## 心情

心情使用愉悦程度、唤醒程度和主导感三个维度表示。愉悦程度反映舒服或不舒服，唤醒程度反映平静或激动，主导感反映自主或受压制的倾向。

当前互动经理解与情绪评估后推动心情；推动幅度受互动强度、人格、语气和现有状态影响。没有有效情绪输入时，不要求每轮产生变化。心情是一段时间内的背景状态，离散情绪则描述某次互动的具体反应。

## 人格与人物感受

五项人格倾向参与评估和状态变化；特别在意的事项可以放大某类触动。对人物的感受与总体心情分别维护：角色心情低落，不等于对所有人失去信任。

棱镜的人物感受与光谱的好感、信任是不同状态来源。接入时用于补充主观底色，不直接替代光谱的关系和事实记录。

## 经历与显著性

场景保存一段连续经历，包括在场人物、发生内容和角色当时的感受。情绪、反常程度和关系重要性影响显著性，进而影响记忆痕迹。主观回忆文字由模型整理，因此可能保留偏重或误解。

## 淡化与回想

记忆强度使用随时间衰减的模型，基础形式为：

`当前强度 = 已记录强度 × 0.5^(经过时间 / 有效半衰期) × 回想加固系数`

有效半衰期会受显著性、编码时情绪唤醒和回想次数影响。“基础记忆淡化周期”只设定基准，不能据此推断每条记忆恰好在同一时间减半。强度过低时不再被普通召回选择，但底层记录仍保留。

人物、话题和当前心情作为联想起点，沿联想关系扩散，再结合状态排序、强度与可见范围挑选回忆。被想起的经历会加固，也可能进入再巩固窗口，之后对经历的理解可被更新。

## 如何调整

先使用默认值观察一段完整对话。回忆文字形成太慢时看场景整理数量与安静等待；太容易淡忘时调整基准周期或手动加固；情绪过敏时先检查人格、在意事项和模型理解，再改数值。

上述参数描述当前工程实现，不是经过个体校准的真人心理测量。改变数值会改变模拟倾向，不能保证某种固定的回复风格。
