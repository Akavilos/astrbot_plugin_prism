# 棱镜 · Prism

棱镜是 AstrBot 的主观情绪与经历记忆插件。它从角色的视角理解对话，维护心情、对人物的感受、场景记忆和联想，让相关经历随人物、话题与心情被想起。

**棱镜与光谱可以合作运行，构成由状态驱动的角色对话模式：棱镜提供主观感受与回忆，光谱维护共同生活、行为和对外回复。棱镜是可选组件，光谱无需安装棱镜也能运行。** 棱镜自身也可以独立记录状态，但不会自动替框架生成聊天回复；需要由光谱或其他接入方使用它提供的信息。

本版本：**0.2.2**。插件已实现，可直接使用。

## 主要功能

- 理解当前互动，结合人格倾向更新主观心情和对人物的感受。
- 将连续往来整理为经历场景，可生成第一人称回忆文字。
- 通过人物、话题、情绪和联想关系召回经历。
- 模拟记忆淡化、回想加固和再巩固；淡化不等于删除记录。
- 提供独立数据面板，查看场景、记忆强度、联想图、人物与心情。
- 分别控制对外共享的心情、人物感受、回忆和近期联系人信息。

## 安装与开始使用

1. 使用 AstrBot **4.24.0 或更新版本**，先配置可用模型。
2. 将 `astrbot_plugin_prism` 放入 AstrBot 的 `data/plugins` 并加载。
3. 插件配置 → 开始使用，检查“启用棱镜”已开启。模型留空时按框架可用提供商选择，也可明确指定。
4. 人格与记忆设置先保留默认，保存并重载插件。
5. 配合光谱时，开启光谱的“使用棱镜的心情与回忆”。发送 `/棱镜` 查看状态，`/棱镜 想` 查看此刻的联想回忆。

棱镜对对话理解和场景整理会产生模型调用。它保存的是角色的主观版本，心情与回忆作为表达背景，不能据此替代共同现实、人物身份或约定状态。

## 升级与数据

新版分组配置会保留旧设置。场景、记忆痕迹和联想图保存在独立插件数据目录中的 `prism.db`；升级源码时保留配置与数据。心情不一定每轮变化，回忆也不要求每轮出现。


## 全新安装与个人数据

发布源码不包含聊天记录、个人实例的数据库、私人配置或部署凭据。全新数据目录从空的业务数据开始；升级已有实例时保留原数据。
