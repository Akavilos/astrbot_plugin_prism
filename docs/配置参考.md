# 棱镜配置参考

适用版本：0.2.2。在 AstrBot 插件配置中按下列分组设置，保存后重载插件。默认值指全新安装；升级保留原值。

先完成“开始使用”，其他分组按需要调整。页面中的隐藏旧字段用于升级兼容，不是新增功能。

## 开始使用

### 启用棱镜

默认：开启。

记录角色主观经历、心情和对人的感受。关闭后停止参与，已有记忆保留。棱镜本身不负责向用户发送聊天回复。

配置标识：`basic.enabled`。

### 棱镜使用的模型

默认：空（未填写）。

留空使用框架当前模型；也可从已配置的模型提供商中选择一个。用于情绪解读与场景整理，不要求与光谱使用同一模型。

配置标识：`basic.provider_id`。

## 人格与情绪倾向

### 开放性

默认：0.6。

范围 0～1，越高越重视探索、新鲜体验和理解。0.5 表示中间水平；这是情绪与目标计算的倾向，不是固定回复模板。

配置标识：`personality.trait_openness`。

### 尽责性

默认：0.5。

范围 0～1，越高越重视秩序、目标和完成事情。通常先保留默认值，再按角色性格微调。

配置标识：`personality.trait_conscientiousness`。

### 外向性

默认：0.55。

范围 0～1，影响情绪表达倾向、活跃程度和恢复速度。越高通常越愿意表达，不保证每条消息都主动回应。

配置标识：`personality.trait_extraversion`。

### 宜人性

默认：0.8。

范围 0～1，越高越重视关系、体谅与合作。它不要求角色总是顺从，也不直接规定回复内容。

配置标识：`personality.trait_agreeableness`。

### 情绪敏感性

默认：0.6。

对应大五人格的神经质维度，范围 0～1。越高，情绪反应通常越强、恢复较慢；没有人格好坏之分。

配置标识：`personality.trait_neuroticism`。

### 特别在意的事情（可选）

默认："{}"。

初次使用保留 {} 即可。需要细调时，按示例填写事项和敏感倍率：{"被忽略": 1.5}。1 为正常，大于 1 更敏感；这里使用 JSON 对象格式。

配置标识：`personality.cares`。

## 经历与回忆

### 场景整理的消息数量

默认：12。

每积累多少条消息考虑整理一次经历。默认 12；过小容易把连续对话拆碎，过大会延后文字回忆生成，可能影响模型调用次数。

配置标识：`memory.recall_every`。

### 生成主观回忆文字

默认：开启。

开启后，用模型将场景写成角色的回忆。关闭后仍保存场景基础记录，但不生成这部分叙述；通常保持开启。

配置标识：`memory.write_narrative`。

### 对话结束后的整理等待（分钟）

默认：10。

会话安静多久后封存场景，并在开启回忆文字时整理叙述。不会让这段时间的基础记录等待落盘。

配置标识：`memory.idle_seal_minutes`。

### 基础记忆淡化周期（小时）

默认：72。

记忆强度自然减半的参考时长，默认 72 小时。重要程度、人格和回想会影响实际淡化；淡化不等于删除记忆。

配置标识：`memory.half_life_hours`。

## 提供给光谱等插件的信息

### 共享对当前人物的感受

默认：开启。

允许光谱等插件参考角色对当前人物的情感底色。关闭后不提供这部分感受。

配置标识：`sharing.share_interperson`。

### 共享当前心情

默认：开启。

允许光谱等插件参考角色此刻的主观心情。关闭后不对外提供心情，棱镜内部仍可记录与变化。

配置标识：`sharing.share_mood`。

### 共享相关回忆

默认：开启。

允许光谱等插件获取与当前话题和人物相关的主观回忆。关闭后停止对外提供，不删除已有回忆。

配置标识：`sharing.share_recall`。

### 共享近期联系人的身份

默认：开启。

提供最近与角色交流过的其他人的名字和平台身份，帮助区分谁说过什么。保持开启有助于减少跨会话认错人，但不保证模型绝不混淆。

配置标识：`sharing.share_recent_others`。
